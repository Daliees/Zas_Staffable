# Zas_Staffable

A JSON-based staff management system.

## Files

- `staff.json` - Sample staff data in JSON format
- `schema.json` - JSON schema defining the structure of staff data

## Data Structure

The staff data follows a JSON format with the following structure:

```json
{
  "staff": [
    {
      "id": 1,
      "name": "John Doe",
      "position": "Manager",
      "department": "Sales",
      "email": "john.doe@example.com",
      "hired_date": "2023-01-15"
    }
  ]
}
```

## Usage

The JSON files can be used for:
- Storing staff information
- Validating data against the schema
- Importing/exporting staff data
- Integration with other systems
